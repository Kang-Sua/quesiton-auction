# 질문 경매장

독서인문 수업 《우리 학교가 사라진대요!》 3차시용 도구입니다.
학생이 사실·논쟁·성찰 질문을 만들고, 논쟁·성찰 질문을 경매에 부쳐
가장 이야기하고 싶은 질문을 함께 고릅니다.

---

## 수업 흐름

| 단계 | 학생 화면 | 교사 화면 |
|---|---|---|
| 모이기 | 대기 | 들어온 사람 확인 |
| 질문 쓰기 | 사실 / 논쟁 / 성찰 탭에 하나씩 | 몇 명이 보냈는지 |
| 사실 질문 | 목록 보기 | 눌러서 줄 긋기 (함께 답 찾으며) |
| 경매 | 1000원을 100원씩 배분 | 입찰 현황, 질문 직접 올리기 |
| 낙찰 | "앞을 보세요" | 순위·금액·작성자 공개 |

단계는 교사 화면의 버튼으로만 넘어갑니다. 학생 화면은 자동으로 따라옵니다.

**넣어 둔 장치**

- 자기가 쓴 질문에는 입찰할 수 없습니다.
- 경매 중에는 작성자가 보이지 않고, 낙찰 화면에서만 공개됩니다.
- 사실 질문은 경매에 오르지 않습니다.
- 남은 돈이 동전 열 개로 보입니다.

## 1. GitHub에 올리기

1. GitHub에서 **New repository**를 눌러 저장소를 만듭니다. Public으로 두세요.
2. **Add file → Upload files**로 이 폴더의 파일을 전부 올립니다.
   폴더 구조를 그대로 유지해야 합니다.
   ```
   index.html
   config.js
   README.md
   .nojekyll
   assets/style.css
   assets/app.js
   ```
3. **Settings → Pages**로 들어갑니다.
4. Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 두고 Save.
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 열립니다.

이 주소를 학생들에게 알려 주면 됩니다. QR 코드로 만들어 두면 편합니다.

## 2. Firebase 연결하기

**이 단계를 건너뛰면 기기 사이에 자료가 오가지 않습니다.**
설정 없이 열면 "혼자 연습 모드"로 켜지고, 같은 기기의 여러 탭끼리만 맞춰집니다.
미리 눌러 보며 익히는 데는 쓸 수 있지만 수업에는 쓸 수 없습니다.

무료이고, 한 번만 해 두면 됩니다.

1. [console.firebase.google.com](https://console.firebase.google.com) 에 구글 계정으로 들어갑니다.
2. **프로젝트 만들기** → 이름을 아무거나 정합니다. Google 애널리틱스는 꺼도 됩니다.
3. 왼쪽 메뉴에서 **빌드 → Realtime Database** → **데이터베이스 만들기**.
   위치는 `asia-southeast1`을 고르세요.
   보안 규칙은 일단 **테스트 모드로 시작**을 고릅니다.
4. 프로젝트 개요 옆 **⚙ → 프로젝트 설정** → 아래로 내려 **내 앱**에서
   웹 아이콘(`</>`)을 누르고 앱을 등록합니다.
5. 화면에 나오는 `firebaseConfig = { ... }` 안의 내용을 복사합니다.
6. `config.js`를 열어 `firebase: null`을 지우고 그 자리에 붙여 넣습니다.

```js
window.QA_CONFIG = {
  firebase: {
    apiKey: "AIzaSy...",
    authDomain: "내프로젝트.firebaseapp.com",
    databaseURL: "https://내프로젝트-default-rtdb.asia-southeast1.firebasedatabase.app",
    projectId: "내프로젝트",
    storageBucket: "내프로젝트.appspot.com",
    messagingSenderId: "000000000000",
    appId: "1:000000000000:web:abcdef"
  },
  defaultRoom: "6학년",
  purse: 1000,
  step: 100
};
```

`databaseURL`이 빠져 있으면 반드시 채워 넣으세요. Realtime Database 화면 위쪽에 있습니다.

### 보안 규칙

테스트 모드는 30일 뒤에 잠깁니다. 수업용으로는 다음 규칙을 넣어 두세요.
Realtime Database → **규칙** 탭입니다.

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

주소와 방 번호를 아는 사람은 누구나 읽고 쓸 수 있다는 뜻입니다.
학급에서 쓰기에는 문제가 없지만, 개인정보는 적지 않도록 안내해 주세요.
학생 이름 대신 번호를 쓰게 해도 됩니다.

## 3. 수업 중에

- 교사와 학생이 **같은 방 번호**를 넣어야 합니다. `config.js`의 `defaultRoom`을
  학급 이름으로 바꿔 두면 학생이 따로 입력하지 않아도 됩니다.
- **"진행하기"는 선생님만** 고릅니다. 두 명이 고르면 단계가 서로 밀립니다.
- 수업이 끝나면 교사 화면 맨 아래 **"모두 지우기"**로 정리합니다. 두 번 눌러야 지워집니다.
- 이름이나 역할을 잘못 골랐으면 **"나가기"**를 누르고 다시 들어옵니다.
  (학생은 브라우저의 새로고침 뒤에도 그대로 유지됩니다.)

**낙찰된 질문은 종이에 크게 옮겨 적어 교실에 붙여 두세요.**
화면은 다음 시간에 남지 않습니다.

---

## 4. 고칠 만한 것

`config.js`에서 바꿀 수 있습니다.

| 항목 | 뜻 | 기본값 |
|---|---|---|
| `defaultRoom` | 방 번호 기본값 | `"6학년"` |
| `purse` | 학생 한 명이 가진 돈 | `1000` |
| `step` | 한 번에 움직이는 단위 | `100` |

`purse ÷ step`이 동전 개수가 됩니다. 기본값은 열 개입니다.
`assets/style.css` 맨 위의 색 값도 바꿀 수 있습니다.

## 만든 것

- 화면: HTML + CSS + 바닐라 자바스크립트. 빌드 도구가 필요 없습니다.
- 동기화: Firebase Realtime Database (없으면 localStorage).
- 글꼴: Pretendard (CDN).
